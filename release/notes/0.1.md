MesOS 0.1 Developer Preview — first bootstrap release.

- MesOS Home: clock and date, pinned apps, dock, swipe-up app drawer with search
- MesOS Settings: Network, Display (MesOS light/dark appearance), Sound, Apps, Storage, System, About MesOS
- MesOS Update: checks GitHub for new MesOS releases and installs them after SHA-256 and signature verification
